## Structured data review

| Type | Status | Decision |
|---|---|---|
| Organization | Present (layout) | **Kept.** The description now names UGC. It has name, legalName, logo, email, contactPoint (sales, email + enquiry URL), areaServed, sameAs (Instagram and LinkedIn), knowsAbout, and an OfferCatalog of real service URLs. **No address, telephone, ratings, reviews, awards or founding date**, because none are verified. |
| WebSite | Present | Kept. No SearchAction, since the site has no site-search URL. |
| WebPage | Present | Kept. Its name and description update automatically from the new title and description. |
| FAQPage | Present | **Kept, with a caveat.** Since August 2023 Google limits FAQ rich results to well-known government and health sites, so this markup **won't produce a rich result** for Kudozz. It stays because it mirrors visible content exactly and is valid schema that other search engines and AI systems can read. It wasn't added in order to get a rich result. |
| Service | Not on the homepage | **Not added.** Each service page already emits Service schema (`serviceSchema`), and Organization.hasOfferCatalog lists them. Repeating them on the homepage would duplicate entities with no benefit. |
| LocalBusiness / AggregateRating / Review | Absent | **Correctly absent.** There is no verified address, reviews or ratings. |

**Validation limits:** Google's Rich Results Test and validator.schema.org need a public URL, and this change isn't deployed. Run both on `https://www.kudozz.in/` after deployment (listed in report 08 recommendations). Locally, the JSON parse and the visible/schema FAQ parity were verified.

## Issues found and fixed

1. **Duplicate H3s in the process section.** The desktop and mobile variants both rendered `<h3>` (10 headings for 5 steps). Fixed in `HowItWorks.tsx`.
2. **Fragment H2** "Influencer campaigns for brands in". Replaced with a full section heading and explanatory copy.
3. **The H1's accessible name** read as "…Agency in India : Build your brand's…". It's now a single sentence.
4. **The Organization description omitted UGC.** Fixed in `siteConfig.description`.
5. **Title templating bug risk.** A short title would have become "… | Kudozz — Kudozz". `buildMetadata` now has an `absoluteTitle` option.
