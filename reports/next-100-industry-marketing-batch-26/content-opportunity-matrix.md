# Batch 26: Content Opportunity Matrix (100 proposed topics)

Prepared 2026-11-05 against the local repository at commit `b0d665e`.

## How this was built

- **Library checked:** 984 slugs extracted from `src/content/**` (core `blog.ts`, `brand-guides/`, `creator-economy/`, `creator-resources/`, `gcc-guides/`, `au-guides/`, `uk-guides/`, `location-guides/`, plus services, markets and case studies). Every proposed topic was matched against slugs, titles and excerpts with keyword patterns, and then against the H2 outline of each candidate owner page. Matching on wording alone was not enough to decide.
- **Search demand:** there was **no keyword tool, Search Console export or analytics access** in this session. Every "Search-demand confidence" value is therefore **Unverified**. No volumes, CPCs or rankings are given or implied. Commercial relevance is a judgement based on how close the reader is to hiring an agency.
- **Live site:** the matrix uses the local codebase, which is the source of the live site. The live site itself was not crawled, so any content that exists only in production is not reflected here.
- **Recommendation key:**
  - **Create:** a genuine gap. Implemented in this batch (see `approved-content-plan.md`).
  - **Merge:** folded into one of the Create articles with another proposed topic.
  - **Refresh:** an existing URL already owns the intent and should absorb the missing angle instead of getting a new page. Not implemented; listed for approval.
  - **Skip:** an existing URL already covers the intent well. A new page would cannibalise it.
  - **Defer:** a small genuine gap with weak commercial value or doubtful demand. Kept as Priority 3.

Service links use the five confirmed core services plus the extra service pages found in `src/content/services.ts`. The UGC pages are `/services/ugc-campaigns` and `/services/ugc-content-production`. Other extra pages are `/services/reporting`, `/services/ambassador-programs` and `/services/regional-influencer-marketing`.

Abbreviations: Info = informational, Comm = commercial investigation, Trans = transactional. Mkt = marketing managers / brand teams, Fdr = founders, Fin = finance, Ops = operations, Legal = legal/compliance.
