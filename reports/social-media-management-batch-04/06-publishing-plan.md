# 06 — Publishing Plan (Batch 04)

This is a recommendation; nothing has been published. As in Batch 03, the codebase has no draft flag. To release in waves, comment out the arrays for later weeks in `src/content/brand-guides/index.ts` before each deploy (the guide groups skip missing posts), and set each article's `publishedAt` to its real release date.
